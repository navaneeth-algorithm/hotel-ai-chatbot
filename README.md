**🤔 Decision Point:**
> How will you store your hotel's static and dynamic data on the backend?

Options:
- **Local JSON Files**: Store all hotel data (rooms, services) in static JSON files within your backend project. Data is loaded and saved directly from these files.
- **In-Memory Store**: Data is stored as JavaScript objects/arrays directly in your server's memory. This is quick for prototyping but not persistent.
- **SQLite Database**: Use SQLite, a file-based relational database. You will need to install an ORM like 'sequelize' or 'knex' to interact with it, creating a schema for rooms and services.

**Concepts:** `REST API` `Endpoint Design` `HTTP Methods`
